Project Overview
App Concept: A minimalist, mobile-friendly habit and task tracker.

Tech Stack: React, Tailwind CSS.

Primary Goal: Allow users to manage recurring routines and view their long-term consistency via visual activity mapping.

Phase 1: Core Functionality (Current)
Task Management: Users must be able to create tasks with custom titles.

Flexible Scheduling: Tasks can be assigned as everyday routines or bound to specific days of the week.

Daily Checklist: The main interface should filter and display only the tasks relevant to the current day.

Completion Tracking: Users can check off tasks, which instantly updates their daily record.

Activity Heatmap: A consolidated grid view displaying historical completion data, with color intensity reflecting the volume of completed tasks.

Local Storage: Progress and task lists must be saved persistently on the user device.

Phase 2: Gamification (Upcoming)
Experience Points: Assign and calculate XP for each task completed to reward consistency.

Streak Tracking: Implement logic to detect and display consecutive days of successful activity.

Leaderboards: Introduce a competitive element where users can compare their XP and streaks with others.

Cloud Syncing: Transition from local storage to a backend database for cross-device access and leaderboard functionality.

Design and UX Guidelines
Mobile-First: Interfaces must be constrained to mobile widths and optimized for one-handed use.

Modern Aesthetic: Utilize a dark theme with high-contrast accent colors to indicate success.
